# CodeIgniter POS Foundations

## Description

This project is a basic Point-of-Sale system created using CodeIgniter 4.

It demonstrates:

- CodeIgniter installation using Composer
- URL routing
- Controllers
- Views
- MVC architecture
- Static PHP arrays
- foreach loops
- Navigation between pages

## Pages

- `/` - Landing page
- `/about` - About page
- `/customers` - Customer Accounts
- `/users` - User Accounts
